**1.¿Qué significa programa de forma estructurada?**  
Nuestro programa sigue una estructura fija por estructuras de control, una secuencia, selección e iteración  
**2-¿Cuáles son las tres estructuras fundamentales de control?**  
-For
-While
-If  
**3.¿Qué ventaja tuvo separar el programa en funciones?**  
Se pudo delegar y no sobrecargar funciones y clases.  
**4.¿Qué función tendría que modificarse si la calificación mínima aprobatoria cambiara?**  
Se modifica la función calculaProm() cambiando la calficación en la asignación de estado  
**5.¿Qué diferencia conceptual observa entre una función y un método?**  
La función actúa independiente de los atributos de una clase u objetos, un método pertenece a alguna.  
**6.¿Qué representa un commit en Git?**  
Un punto de guardado de los cambios al proyecto o ciertos archivos del mismo  
**7.¿Por qué es preferible realizar varios commits pequeños en lugar de un solo commit final?**  
Para poder tener mucho mejor control del proyecto y su progreso, de esta forma se minimiza el riesgo de perder control sobre nuestro programa.
